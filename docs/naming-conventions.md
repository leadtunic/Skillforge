# Naming Conventions

Use names that are:

- lowercase
- kebab-case
- action-oriented
- specific to a workflow

## Examples

Good:

```txt
quality-gatekeeper
production-readiness-check
api-contract-steward
```

Avoid:

```txt
helper
reviewer
agent
super-skill
```

## Category Names

Use one of the existing categories unless a new group is clearly needed:

- `strategy`
- `product`
- `engineering`
- `quality`
- `security`
- `operations`
- `devops`
- `docs`
- `design`
- `ai`
- `research`
- `open-source`
