# Release Process

## Before Release

Run:

```bash
npm run check
```

Review:

- skill count
- catalog output
- README accuracy
- duplicate skill names
- descriptions and categories
- unsafe or misleading commands

## Versioning

Use semantic versioning:

- patch: wording fixes or small improvements
- minor: new skills or larger skill improvements
- major: structural changes or breaking conventions

## Release Notes

Use the `release-brief-writer` skill to prepare release notes.
