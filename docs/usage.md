# Usage Guide

## Basic Invocation

Ask your AI agent to use a specific skill by name:

```txt
Use the quality-gatekeeper skill to review this change before merge.
```

## Recommended Workflow

For a new feature:

1. `strategy-pressure-test`
2. `requirements-crystallizer`
3. `product-brief-architect`
4. `architecture-lens`
5. `acceptance-contract-writer`
6. `test-strategy-designer`
7. `pull-request-sentinel`
8. `quality-gatekeeper`
9. `release-brief-writer`

For a production deployment:

1. `environment-contract-validator`
2. `docker-compose-auditor`
3. `dokploy-launchpad`
4. `traefik-route-detective`
5. `production-readiness-check`
6. `observability-architect`
7. `backup-restore-guardian`

For open-source repository polish:

1. `repository-cartographer`
2. `readme-polisher`
3. `documentation-architect`
4. `open-source-maintainer-kit`
5. `changelog-curator`
6. `release-brief-writer`

## Best Practices

- Prefer one skill per task.
- Combine skills only when the task clearly spans multiple domains.
- Keep outputs short enough to act on.
- Ask the agent to produce required fixes separately from optional improvements.
